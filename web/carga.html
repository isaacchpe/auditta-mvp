Qué pasa con el documento

  1. Se extrae el texto y se segmenta por secciones clínicas.
  2. Se anonimizan localmente los datos del paciente y del profesional: el PDF original no se conserva en el servidor.
  3. Usted revisa el texto anonimizado y confirma.
  4. Solo entonces el texto anonimizado se envía al modelo de lenguaje para generar los hallazgos.
